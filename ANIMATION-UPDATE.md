# Animation update — based on your original portfolio

Open index.html in your browser with the assets folder beside it.

The highlighted introduction types and deletes between:
- Hi, I am Jacky Leong Kin Yin
- I am a FinTech Student in APU
- I am Jacky Leong Kin Yin

After the initial greeting, the student role and name repeat. Each completed phrase stays for about 2.3 seconds. Space is reserved for the longest heading to avoid shifting the page. The existing language selector also updates the animated introduction.

About, projects, experience, certificates, life, music and contact content slide into view when scrolling or using the existing navigation. Paired cards alternate between left and right entrances. They can animate again after leaving the viewport completely.

Pause animation stops the typing and scenery and displays all section content. Reduced-motion system preferences show a static introduction and content without entrances. Without JavaScript, the original heading and all content remain visible.

To update GitHub Pages, replace index.html and add assets/motion.css and assets/motion.js. Keep all original photos and documents. No build or installation is needed. This version does not include the previous reading-size or wildlife redesign.
