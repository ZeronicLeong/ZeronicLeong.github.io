# Jacky Leong — Portfolio prototype

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript. It has no build step, server dependency, or package installation. The `assets` folder contains the supplied photos and certificates.

## Run it

Open `index.html` in a browser. To work on it in Visual Studio, open the `jacky-portfolio` folder and edit `index.html`; you can launch the page in a browser from the IDE. The site also works when hosted as static files.

## Prototype features

- Dark mode by default with the requested cyan/charcoal palette, plus a header toggle for the cream/blue light palette. The selected theme is remembered in that browser.
- An ambient sky with drifting clouds in both modes, stars and occasional shooting stars at night, and randomly ordered animal silhouettes moving across the page.
- The moon has a left-to-right phase cycle; the sun remains a glowing disc with rays. The animal movement and sky animations respect reduced-motion preferences.
- Responsive layout for desktop and mobile.
- Clickable project cards with detail dialogs and links to GitHub or Devpost.
- A profile photo, hiking and charity event photos, and a TikTok profile screenshot.
- Clickable certificate cards that open the supplied image or PDF certificate.
- GitHub, LinkedIn, and email links.

## Personalise it

Project descriptions and tags are in the `projects` array near the bottom of `index.html`. Add screenshots, your exact contributions, and technical details as you refine each project. The TikTok image is a profile screenshot; add a profile link if you want visitors to find the account directly. The portfolio content is a first pass from the supplied resume, certificates, and profile links; confirm details before publishing.
